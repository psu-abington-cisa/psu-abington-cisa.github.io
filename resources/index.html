CISA Linux

A hacking lab that feels like home.

A Linux system for students who’ve only ever used Windows. The taskbar, Start menu and shortcuts work the way you expect, and the security tools from our sessions are already installed.

  • Feels like Windows. Start menu, taskbar and system tray, plus Win+E, Win+L and Print Screen.
  • Tools grouped by topic. Recon, Web, Passwords, Exploitation, Forensics and Reverse Engineering, each with a short explanation.
  • Ready for the labs. Import your TryHackMe or OffSec VPN file in two clicks.
  • Stable. Built on Debian 13 with Secure Boot support. Run it from USB, in a VM, or next to Windows.

CISA Rice

Make it yours in one command.

View on GitHub →

After installing CISA Linux, open the terminal and paste this. Pick a theme, and it changes your colors, wallpaper, icons, taskbar and terminal in one go. Switch any time from Start → CISA Themes, or undo with --restore.

Bonus: the terminal prompt shows your VPN IP when you’re connected to TryHackMe or OffSec, so it’s ready to paste into a reverse shell.
