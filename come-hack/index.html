What We Do

The goal is to move beyond simply reading about security. Each meeting combines guided learning with practical exercises using cyber ranges and custom-built labs.

Offensive Security

  • Web application hacking
  • Linux system exploitation
  • Windows system exploitation
  • Standalone target machines
  • Chained attack paths
  • Active Directory environments
  • Enterprise Security
  • AI assisted operations

Defensive & Analysis

  • Blue-team exercises
  • Security analysis
  • Phishing Analysis
  • Log and artifact analysis
  • Incident investigation concepts
  • OSINT techniques
  • Detection and defensive thinking

Cyber Ranges

Depending on the topic, we will work through public cyber ranges, intentionally vulnerable systems, and custom-made labs.

Who Is It For?

Anyone interested in cybersecurity, offensive security, defensive security, penetration testing, security research, OSINT, or IT in general.

You do not need to be an expert. The sessions are intended to give people a place to learn, experiment, ask questions, and practice security skills.

What To Bring

A laptop is recommended, but not mandatory.
Workstations will be available for attendees. If you bring a laptop, you can use it to access browser-based labs and, when appropriate, local virtual machines or other security tooling.

Ground Rules

Everything we practice should be done against systems we own, systems explicitly provided for training, or systems for which we have permission to test.

The objective is to develop practical security skills responsibly — not to attack real-world systems without authorization.
